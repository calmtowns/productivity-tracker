# Трекер продуктивности

Приложение для ежедневного отслеживания выполнения задач с аналитикой прогресса.

## Функции

- ✅ Ежедневное добавление плана (количество задач на день)
- ✅ Отметка выполнения (сколько задач выполнено)
- ✅ Автоматическое вычисление процента выполнения
- ✅ График прогресса за последние 7 дней
- ✅ Отчёт за каждые 3 дня
- ✅ История всех записей
- ✅ Локальное хранилище (данные остаются на устройстве)

## Как запустить локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000 в браузере.

## Развёртывание на Vercel

1. Подключи репозиторий к Vercel
2. Vercel автоматически развернёт приложение
3. Получи ссылку и открой на айфоне

## Технологии

- React
- Next.js
- Recharts (графики)
- Vercel (хостинг)
